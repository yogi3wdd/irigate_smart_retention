# IriGate Smart Retention

Project untuk monitoring kolam retensi dan mengontrol gate pada kolam retensi sebagai irigasi. Menggunakan liquid glass effect. Platform yang didukung adalah Android dan iOS. Aplikasi bisa di download pada kolom release.

## 📦 APK Release Files

Berikut adalah APK hasil build Flutter untuk berbagai arsitektur CPU Android:

- **`app-armeabi-v7a-release.apk`**  
  Untuk perangkat Android dengan CPU **ARM 32-bit (ARMv7)**.  
  Cocok untuk HP lama.

- **`app-arm64-v8a-release.apk`**  
  Untuk perangkat Android dengan CPU **ARM 64-bit (ARMv8)**.  
  Digunakan oleh sebagian besar HP Android modern.

- **`app-x86_64-release.apk`**  
  Untuk perangkat dengan CPU **x86_64 (Intel/AMD)**.  
  Biasanya untuk **emulator** atau perangkat khusus.

## 📦 iOS Release File

Berikut adalah file hasil build Flutter untuk perangkat iOS:

- **`app-release.ipa`**  
  File instalasi aplikasi untuk **iPhone dan iPad**.  
  `.ipa` adalah setara dengan APK di Android, namun hanya bisa dibuild menggunakan **Xcode di macOS**.  
  File ini dapat diinstall melalui:
  - **TestFlight** (metode resmi untuk pengujian)
  - **App Store** (setelah proses review)
  - **Sideloading** menggunakan AltStore / Sideloadly
  - **MDM / Enterprise Distribution**
